Урок 3: Обектно-ориентиран подход с примери

Модул 1: ООПП (11. клас)

Група живи организми могат да бъдат разделени в два класа – „Животни“ и „Растения“. Нека се опитаме да изразим мислите си така, че компютърът да е в състояние да разбере какво се опитваме да кажем.

Създаване на клас и полета

Класът дава общото описание на даден обект. В тялото на класа се дефинират полетата (променливите) и методите, които заедно се наричат членове на класа.

Полетата се декларират по същия начин, както обикновените променливи, и описват характеристиките на обекта:

  • string kindOfAnimal; - низов тип за вида на животното
  • string color; - низов тип за цвета
  • int numberOfLeg; - целочислен тип за броя лапи

Създаване на обекти

Процесът на създаване на обект от клас се нарича „деклариране на обект“ или създаване на „инстанция на класа“. Това се случва в главния метод (Main) чрез ключовата дума new:
Animal animal = new Animal();

Присвояване на стойности

Всеки обект може да се разглежда като голяма кутия с наредени в нея по-малки кутии (полета). Два обекта от един и същ клас имат едни и същи полета, но стойностите, съхранени в тях, могат да бъдат различни.

За да кажем на компилатора да съхрани информация в дадено поле на конкретен обект, използваме името на обекта, последвано от точка (.) и името на полето.

Проследете как се създава обект и как се пълнят неговите полета!
Обект: animal (Клас Animal)
kindOfAnimal null
color null
numberOfLeg 0
hasTail False
class Animal
{
    public string kindOfAnimal;
    public string color;
    public int numberOfLeg;
    public bool hasTail;
}
class Program
{
    public static void Main(string[] args)
    {
        Animal animal = new Animal();
        animal.kindOfAnimal = "Cat";
        animal.color = "Black";
        animal.numberOfLeg = 4;
        animal.hasTail = true;
        Console.WriteLine("Kind of animal: " + animal.kindOfAnimal);
        Console.WriteLine("Color: " + animal.color);
    }
}
