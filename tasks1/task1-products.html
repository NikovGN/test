Задача 1: Изделия

Тематични задачи

Да се създаде конзолно приложение за описание на изделия. В него да се декларира клас Product (изделие) със следните полета:

Поле Тип Описание
description низ описание на изделието
partNum цяло число номер на изделие
cost реално число цена на изделие

Да се извършат следните действия:

а) Да се създадат две изделия и се инициализират чрез следните данни:

description partNum cost
screw-driver 456 5.50
hammer 324 8.20

б) Да се изведат на екрана компонентите на двете изделия, дефинирани в а), както е показано на долната фигура.

Подсказка: namespace izdelia { class Product { public string description; // Добавете останалите полета тук } class Program { public static void Main(string[] args) { Product p1 = new Product(); p1.description = "screw-driver"; Console.WriteLine("Description: " + p1.description); Console.WriteLine("PartNum: " + p1.partNum); Console.ReadKey(true); } } }
Проследете създаването на обектите и резултата в конзолата!
